# Armando Tapia

**Consultor de adopción de IA para PyMEs y empresas · Docente en UNAM FES Cuautitlán · 30+ años en TI corporativa**

Me enfoco en que PyMEs y empresas adopten IA con un plan claro: diagnóstico digital, agentes que automatizan tareas concretas y capacitación práctica para sus equipos. Los proyectos de abajo son públicos, con su código y su documentación.

## Áreas de trabajo

- **Orquestación multiagente:** agentes especializados coordinados con la API de Claude, con salidas validadas y control de costo por corrida.
- **MCP (Model Context Protocol):** servidores y clientes que conectan datos y herramientas de negocio con asistentes de IA.
- **Diagnóstico digital para PyMEs:** cuestionarios y puntajes que se convierten en un plan de acción.
- **Docencia:** cursos y materiales de JavaScript, Java y Git/GitHub para Educación Continua de la UNAM FES Cuautitlán, con evaluación automatizada.
